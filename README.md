# 💎 CristalCaisse – Disponible sur Windows, macOS et Linux !

🎉 **CristalCaisse arrive officiellement en application sur les trois grands systèmes d'exploitation !**

Après son développement et ses premiers tests sur Windows 11, CristalCaisse s'ouvre désormais à de nouveaux utilisateurs avec une version destinée à **Windows, macOS et Linux**.

Notre objectif : proposer une solution de caisse moderne, accessible et simple à utiliser, quel que soit votre ordinateur.

---

## ✨ À propos de CristalCaisse

CristalCaisse est une application de caisse enregistreuse conçue pour faciliter la gestion d'une caisse et rendre son utilisation accessible.

Le projet évolue continuellement afin d'améliorer l'expérience utilisateur et d'assurer une meilleure compatibilité avec différents systèmes.

---

## 🧪 Participez aux tests !

Windows 11 a déjà été utilisé pour les premiers tests. Nous souhaitons maintenant élargir les essais à macOS et Linux.

- Vérifier que l'application démarre correctement.

- Repérer les bugs et problèmes d'affichage.

- Proposer des améliorations.

Chaque retour nous aide à rendre CristalCaisse plus fiable !
