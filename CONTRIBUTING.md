# Contribuer à CristalCaisse

Merci de vouloir contribuer à CristalCaisse !

## Proposer une modification

1. Forkez le dépôt [CristalCaisse-app](https://github.com/RP4031-FR/CristalCaisse-app).
2. Créez une branche dédiée à votre modification.
3. Effectuez vos changements dans le dossier `desktop` (notamment `desktop/index.html`, `desktop/main.js` ou les fichiers de configuration concernés).
4. Testez l'application sur votre plateforme si possible.
5. Envoyez une Pull Request en décrivant clairement vos changements.

## Signaler un bug

Ouvrez une [issue GitHub](https://github.com/RP4031-FR/CristalCaisse-app/issues) en indiquant votre système d'exploitation, la version de CristalCaisse et les étapes pour reproduire le problème.
